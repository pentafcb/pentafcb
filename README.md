## Main project — Syn Wallet

<p align="center">
  <a href="https://github.com/pentafcb/Syn-Wallet">
    <img src="https://r2.fivemanage.com/WD0UYkJxI50yH1OBccdt2/gitbanner.png" alt="Syn Wallet" width="100%" />
  </a>
</p>

**[Syn Wallet](https://github.com/pentafcb/Syn-Wallet)** is a non-custodial, phone-first web crypto wallet. Keys are generated and encrypted locally in your browser (AES-256-GCM vault, PBKDF2 600k) — the server never sees a seed phrase or a private key.

- Create/import wallets (12/24-word seed or private key) for **Solana, EVM chains, Bitcoin, Sui, Aptos, XRP and Cosmos**
- Swaps via Jupiter and LI.FI, quote-verified before signing · Staking · NFTs with spam quarantine · ENS/SNS
- **Invest:** native in-wallet Hyperliquid perps trading, Polymarket prediction markets, Binance bStocks
- WalletConnect · 12 display currencies · desktop layout · live open positions in Activity
