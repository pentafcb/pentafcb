### [Syn Wallet](https://github.com/pentafcb/Syn-Wallet) — main project

Non-custodial, phone-first web crypto wallet. Keys are generated and encrypted locally in your browser — the server never sees a seed phrase or a private key.

Solana · EVM · Bitcoin · Sui · Aptos · XRP · Cosmos — swaps, staking, NFTs, native Hyperliquid perps, Polymarket and Binance bStocks, all in one wallet.
